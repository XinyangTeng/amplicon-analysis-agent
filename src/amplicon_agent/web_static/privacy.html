隐私政策与研究数据处理说明

雏形版本 · 面向邀请制测试。正式上线前应由实际运营主体完成法律审阅并补充主体信息。

1. 我们处理哪些信息

账户信息包括邮箱、显示名称、密码的不可逆哈希、邀请码使用记录和登录会话。分析数据包括你主动上传的丰度表、分类注释表、样本信息表及可选文件，以及由此生成的计划、日志、图表、结果表和报告。

2. 处理目的

上述信息仅用于身份验证、隔离个人工作区、执行你审批的分析、提供结果报告、控制资源和模型额度、定位运行错误以及执行数据删除。

3. 模型服务与第三方传输

统计计算不调用大模型。只有当你主动在 AI 助手中发送消息、点击“模型解读”或“测试连接”时，系统才会调用所选模型接口。数据检查阶段仅发送 metadata 的列结构、取值摘要和有限代表行，不发送完整丰度矩阵；结果解读发送实验设计和已校验的结构化结果摘要。若使用站点共享模型，以上内容会发送给站点配置的模型提供商；若填写自己的 API Key，密钥只在当前浏览器会话和本次请求内使用，不写入应用数据库或报告。共享额度只在模型调用成功后扣除。

4. 保存期限与自动删除

当前默认保留期为 {{RETENTION_DAYS}} 天。上传、分析计划和结果到期后由后台任务自动删除。实际部署可调整保留期，账户页会显示当前账户的期限。

5. 隔离与安全措施

每位用户使用独立运行目录，接口检查资源归属；任务通过独立队列执行，并在容器层限制 CPU、内存、并发和运行时长；上传文件类型、单文件大小、单次总量和个人存储量均受限。任何联网系统都无法承诺绝对安全，因此请勿上传直接身份标识、医疗隐私或无权处理的数据。

6. 你的选择

你可以在工作台“我的账户”中随时删除全部研究数据，或永久注销账户。删除会尽力取消排队或运行中的任务，并清除上传、计划、结果和模型调用记录。已进入第三方模型接口的数据需遵循对应提供商的政策。

7. 研究责任

本工具用于辅助科研分析，不替代研究者对实验设计、统计假设、数据合规和论文结论的最终判断。报告中的自动解释应结合原始实验背景复核。
