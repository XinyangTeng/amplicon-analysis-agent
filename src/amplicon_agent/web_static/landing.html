工作方式

四个阶段，不是一键黑箱

Agent 把研究问题转成计划，计算交给已登记的统计函数。

01

先诊断输入

表方向、样本对应、分组重复自动判断，不合格数据运行前阻断。

02

再确认设计

明确处理与参照、梯度和批次，决定分析范围。

03

审批后执行

一次性审批码；输入或参数一变，旧审批立即失效。

04

校验后解释

解读只读已校验摘要，区分证据、推断与局限。
