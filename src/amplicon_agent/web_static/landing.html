HOW IT WORKS

不是“一键黑箱”，而是四个可核对阶段

Agent 负责把研究问题转译为清晰计划；统计分析仍由经过登记和校验的函数执行。

01

先诊断输入

自动判断丰度表方向、样本与特征对应、分组重复和分析条件，不合格的数据会在运行前阻断。

02

再确认设计

明确样本类型、处理与参照、梯度和批次，决定做全套分析还是只回答当前科学问题。

03

审批后执行

计划使用一次性审批码。输入或参数变化后旧审批立即失效，避免误跑和不可追溯的修改。

04

校验后解释

报告脚本自动收集 PNG 图、结果表、日志和版本；模型只读取已校验摘要，区分证据、推断与局限。
